# Local by Local v3.8

Current release: **v3.8**. Build UTC: 2026-11-13T02:31:51Z.

This package contains the complete Local by Local app, three city datasets, and supporting assets. The active stylesheet, scheduler, HTML badge, PWA manifest, service-worker cache and current release documentation use v3.8.

City data: Chicago, New York City and Los Angeles. The 48-column data contract is associated with **City Database Validator v4.0** (a separate product).

## Deploy
Upload the *contents* of this directory to your hosting root. Ensure `index.html`, `sw.js`, `manifest.json`, `cities/`, `vendor/` and `images/` are all included. Reload after the new service worker activates. Older release notes are preserved in `docs/release_history/` as historical records, not current version labels.
