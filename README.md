# Local Like a Local — Version 2.6

## Release Notes & Key Improvements
1. **Full Editorial Redesign Applied**: Restored the boutique travel magazine styling with Terracotta (#B85F43), Deep Sage (#263D36), Unsplash destination hero photography, and responsive layout grids.

4. **Bakery Dinner Exclusion Rule**: Strictly filters light-bite spots (bakeries, cafes, pastry shops) from Dinner itinerary slots.
5. **Standard Roadmap View**: Forces roadmap mode () across Apple Maps (iOS) and Google Maps (Android/Desktop).
