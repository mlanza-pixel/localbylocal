# Local by Local — Three-City Pilot (v3.61)

Scope: Chicago, New York City, Los Angeles.

City guide appears automatically after city selection; **Read City Guide** reopens it from the directory.

The city JSON files are compatible with the 47-field export schema. Unavailable scores, addresses, hours, and coordinates remain unknown rather than being fabricated.

**Critical data limitation:** The supplied v3.60 city files consisted of generated placeholder venues. These have been removed, leaving empty pilot city arrays. Import real, verified 47-column venue exports from City Database Validator to populate them. Do not publish as a live venue guide until real data is supplied.

Original supplied v3.60 materials and test scripts are retained where useful; browser automation has not been certified in this environment.
